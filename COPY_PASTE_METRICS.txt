- Depths: [2, 2, 6, 2]

- Window size: 7
- Patch size: 4
- Embed dim: 96

- Layers: 2
- Type: 1D CNN
- Stride: 1 (preserves temporal resolution)
- Hidden dim: 512

- Layers: 1
- Type: Conformer
- Heads: 16
- Kernel size: 3
- Dropout: 0.1

- Kernels: [3, 5, 7]
- Type: Gated fusion
- Dropout: 0.1

- Size: 40 phonemes
- 39 phonemes + 1 blank token for CTC

TRAINING COMMAND
================================================================================

bash FINAL_TRAINING_COMMAND.sh

Or directly:

python3 train_swin_vallr.py \
  --data_dir final_preprocessed_dataset_fast \
  --batch_size 1 \
  --epochs 300 \
  --lr 5e-6 \
  --num_workers 0 \
  --checkpoint_dir checkpoints/final_end_to_end_run \
  --time_budget_hours 19.5 \
  --early_stopping_patience 20 \
  --seed 42 \
  --adaptive_validation \
  --disable_curriculum \
  --decorrelation_weight 0.0 \
  --temporal_smoothness_weight 0.0 \
  --attention_entropy_weight 0.0 \
  --temporal_attention_layers 1 \
  --temporal_attention_heads 16 \
  --temporal_attention_kernel 3 \
  --temporal_attention_dropout 0.1
